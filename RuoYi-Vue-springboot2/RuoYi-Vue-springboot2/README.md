# 哪吒魔丸图书管理系统（后端）

> 基于若依 RuoYi-Vue（Spring Boot 2）定制的图书馆管理系统后端，融入「哪吒之魔童降世」修仙世界观：**读者 = 修仙者，功德 = 信用，魔丸 = 失信，灵珠 = 守信**。

在若依原生框架（用户/角色/菜单/公告/日志等）之上，为图书馆业务定制读者自助端接口，并实现一套完整的「修行」玩法与信用判定规则。

## ✨ 核心特色

| 特色 | 说明 |
| --- | --- |
| 🌀 **魔丸/灵珠双身份** | 全局判定读者信用状态，身份实时变化，驱动全部玩法规则 |
| 🧘 **读者修行体系** | 功德 / 境界 / 称号 / 每日奇遇 / 一念成仙净化 |
| 🎁 **功德消费闭环** | 仙丹盲盒（抽奖）、免罚令（兑换），功德不再是只进不出的数字 |
| 📊 **管理数据看板** | 借阅趋势、热门图书、逾期率、魔丸灵珠分布、馆藏统计一屏总览 |
| 🛎 **自动提醒** | 预约到书弹窗、罚金催缴弹窗、逾期冻结提示、还书自动解冻 |

## 📋 功能清单

### 管理端接口
- **数据看板**：借阅趋势、热门图书 Top、逾期率环图、魔丸/灵珠分布饼图、馆藏册数统计（`GET /system/stats/dashboard`）
- **图书管理**：馆藏库存（种数/册数/在借）统一口径，同书不可重复借
- **读者管理**：境界 / 功德 / 魔性展示，隐藏内部读者 ID
- **借阅记录**：书名 + 读者姓名搜索
- **预约管理**：书名 + 读者姓名搜索，到书通知
- **罚金管理**：读者姓名过滤、未缴罚金催缴提醒
- **公告管理**：管理端指南 / 读者指南 / 功能上新分条发布

### 读者端接口
- **在线书城**：浏览图书、在线借书 / 还书 / 续借 / 预约
- **我的借阅 / 我的预约 / 我的罚金**
- **仿支付收银台**：微信 / 支付宝切换 + 仿二维码扫码（演示环境）
- **读者中心（修行面板）**：
  - 每日签到 +15 功德
  - 每日奇遇：登录 20% 概率触发「捡到仙丹 +30」/「遭遇天劫 -10」
  - 称号系统：借阅狂魔（≥10 本）、按时还书模范（≥2 次）、藏书仙人（≥15 本）、罚单大户（≥3 笔）
  - 一念成仙：10 功德净化 1 点魔性，魔丸也能回头
  - **仙丹盲盒**：20 功德/次，随机 +10~200 功德，每日最多 3 次，魔丸不可抽
  - **免罚令**：50 功德兑换 1 张，缴罚金时自动抵消一次
  - **封神榜**：功德排行榜，支持分页，前三名金银铜勋章

### 自动规则
- **魔丸判定**：当前逾期 > 0 ∨ 未缴罚金 > 0 ∨ 魔性 ≥ 30 → 魔丸；否则 → 灵珠（魔性 < 30 也算灵珠）
- **魔性结算**：每逾期一天魔性 +5；罚金落库按金额 ×10 加魔性（幂等推进）
- **账号冻结**：逾期超 3 天自动冻结，还书后自动解冻
- **境界体系**：凡人 / 道童 / 天兵 / 仙将 / 三坛海会大神 / 魔童战神（功德 0 / 100 / 300 / 600 / 1200 / 2500）
- **借阅约束**：借期 30 天、同时最多 5 本、可续借 1 次（+15 天）

## 🛠 技术栈

Java 8 · Spring Boot 2.x · Spring Security · MyBatis · Redis · JWT · MySQL 8+（开发环境 MySQL 9.0.1）

## 🚀 快速开始

### 环境要求
JDK 1.8+ · Maven 3.9+ · MySQL 8+ · Redis 3+

### 1. 初始化数据库
```bash
mysql -uroot -p < sql/ry-vue-init.sql
```
> `sql/ry-vue-init.sql` 为当前最新完整库（含全部表结构、读者/图书/借阅/罚金演示数据与公告）。

### 2. 配置并启动
```bash
# 修改 ruoyi-admin/src/main/resources/application-druid.yml 中的数据源、Redis 地址
mvn spring-boot:run
```
默认端口 `8080`。

### 3. 登录体验
| 账号 | 密码 | 说明 |
| --- | --- | --- |
| `admin` | `admin123` | 管理端 |
| `王强` / `陈静` / `熊安安` 等 | `123456` | 读者端（用户名为读者中文名） |
| `林清风` 等 10 位纯净读者 | `123456` | 0 功德纯净灵珠演示号 |

> 配套前端为 Vue 2 项目（RuoYi-Vue2-master，本仓库未包含），开发端口 81，代理指向 `http://localhost:8080`。
